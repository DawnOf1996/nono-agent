# 学习路径

> 六篇主线，从"Agent 是什么"讲到"这个项目为什么这么设计"。
> 不需要 Agent 开发背景，按顺序读即可。

---

## 为什么从这几篇开始

大多数 Agent 框架的文档直接从"怎么安装"讲起，你很快就装好了，
但还是不知道**为什么**它要由这些零件组成。

这套文档反过来：先让你用二十行代码写一个 Agent，亲眼看到它有多脆弱，
再回头看框架的每个模块在解决哪一个具体的麻烦。
这样每个设计都有来处，而不是一堆需要背诵的名词。

## 阅读约定

这套文档里的事实都对着代码核过：

- 类名、函数名、配置字段、枚举值都能在源码里 grep 到；
- 数量（23 个内置工具、20 个事件类型、11 种终止原因、77 个测试模块）都是**实测值**；
- 遇到代码注释和实际枚举不一致的地方，**以代码为准**，文档里会指出来。

如果你在阅读中发现文档和代码不符，以代码为准，并欢迎提 issue。
